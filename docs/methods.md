# Methods and interpretation

The reference panel (170 individuals, 19,352 SNPs) describes nuclear structure. The landscape panel excludes 221 climate-associated SNPs, leaving 19,131 background markers; the exclusion does not establish neutrality. The SVDQuartets input has 14,766 sites for 170 tips; the TreeMix input has 15,955 loci for 163 individuals in 14 geographic groups. K = 4 describes broad sNMF structure; the numerical cross-entropy minimum was K = 9. The unrooted PAUP tree was inferred independently of the ancestry annotation. R7 records PAUP* v4.0a build 169.

The [contemporary GDM code](../analysis/05_contemporary_GDM/gdm_definitive_spatial_pipeline.R) forms five groups by k-means on scaled, locally approximated equirectangular coordinates of unique localities. R7 calls this an equal-area projection; the approximation in the archived code does not establish that claim. Use the saved fold assignments for a reproduction and reconcile that wording against the executed version. All individuals from the same locality stay together; training pairs have both endpoints in the training set and held-out pairs have both endpoints in the test fold. Compare GRC against GR for climate and against GC for resistance. Each component has its own 999-permutation null; the tests use fold-mean changes in held-out RMSE, not a pooled pair-level RMSE.

BIO4 is displayed as the stored temperature index divided by 100, in °C. This does not alter the original fit or replace the historical input unit harmonisation. For PaleoMean the comparison holds the contemporary predictors and folds fixed and adds the mean of transformed LIG and LGM distances. The significant conditional result for the mean does not imply support for either period tested alone. The Tasmania exclusion checks sensitivity to one region.

The diversity tables use non-imputed genotypes and the same geographic groups as TreeMix. A SNP was retained only when it had calls in at least 70% of each estimable group and three called diploids. Heterozygosity and rarefaction are conditional on SNP ascertainment. The data do not support a matched callable per-base diversity estimate. Pairwise Weir–Cockerham FST intervals use 500 RAD draws. Taxonomy is not inferred from FST.

The folded spectra were projected at 80 × 100, 80 × 80 and 20 × 80 haploid counts for K1–K3, K1–K4 and K2–K4. The [Figure 7 renderer](../analysis/08_demography/plot_figure7_archived.R) uses saved SC fits, masks excluded bins and spaces the colour scale using `asinh(residual / .25)` with labels in original observed-minus-expected mass units. This is not a transformation of the fitted frequency spectrum. The best baseline AIC is not a test against all histories; plotted SC residuals are not independently tested. Expanded size models, four-population tests and dating trials remain separate.
