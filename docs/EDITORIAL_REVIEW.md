# Notes on figures, analysis sources and data access

The repository includes seven main figures, a demographic-model supplement and additional Chapter 2 figures, together with their available plotting scripts, analysis sources and summary tables. Figure 7 is candidate A, not the Stage 11 comparison or candidate B.

The demographic comparison figure was reconstructed from previously estimated models and site-frequency spectrum values. Its PNG is pixel-identical to the selected original; no demographic fit was rerun. The seven original PDFs matched the Drive catalogue by filename and size. The catalogue did not expose a comparable checksum, so local versions are pinned separately by SHA-256. Other figure renderers were checked for source correspondence and R syntax, not executed end to end.

I do not include raw data, heavy objects, exact locality tables, specimen metadata, manuscript drafts or run logs. Figures can reveal information about sampling locations and their reuse conditions should be checked before redistribution. The older geographic sample summary was withheld because its range fields and group–state mapping need review. The complete R7 text was not independently verified.

The README uses the original project illustration. The draft pocket guides and badges are no longer part of the repository presentation. Public rights are documented separately in the [reuse status](../LICENSE-STATUS.md).

The figures and summary tables were collected from the available Chapter 2 and demographic-analysis outputs. The external drive was not mounted during that recovery, so optional copies of the original TreeMix shell and the moments fitting modules were left out. Their existing plotting scripts and aggregate results are included; the paths and dependencies for a complete analytical rerun still need review.

The [private review repository](https://github.com/Nadaline/Lampropholis-delicata-genomic-history-staging) is separate from the original project. It is not approved for public release.
