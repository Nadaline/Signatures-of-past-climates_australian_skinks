# Data availability

The figures and aggregate results are included in this repository. Raw sequences, individual genotypes, exact locality tables and fitted model objects are not included in this repository. The final data accession will be added alongside the associated publication. Request the authorised inputs from the study team; the [input table](../data/provenance.md) identifies separate data products for structure, landscape models, SVDQuartets, TreeMix and moments.

For landscape analyses obtain the author-approved present CHELSA and historical climate layers and effective-resistance inputs. Figure 1 also uses ABS geometry and NVIS vegetation. Check release terms for third-party layers and for the artwork in the README before redistribution. Maintain separate permissions for exact sampling information and the resulting aggregate analyses.
