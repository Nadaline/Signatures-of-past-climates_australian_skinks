# Data dictionary

- TreeMix groups are the geographic analysis units, not K clusters. `colossus` labels Bunya Mountains and does not define species identity.
- Q refers to the fitted ancestry probability. Q ≥ 0.70 is the separate high-ancestry criterion, not a geographic inclusion rule.
- The allelic-richness comparison rarefies to six gene copies. FST is Weir and Cockerham's multilocus θ; report the archived numeric values and RAD bootstrap intervals.
- ΔRMSE is a held-out error reduction under the stated spatial baseline; ΔAIC is relative to the best baseline model within that contrast.
- Projected joint SFS axes are allele counts; the archived mask identifies excluded cells. A masked cell is not an observed zero.
